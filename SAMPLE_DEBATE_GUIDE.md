# Sample UBI Debate Flow

## Overview
The **"📚 Load sample"** button (top-right) pre-populates the app with a complete, realistic APDA debate on Universal Basic Income. This demonstrates how to use all major features of the flow app.

## What's Included

### Motion
**"THW Implement Universal Basic Income (UBI)"**
- Government team: Affirm
- Opposition team: Negate

### Arguments (7 total, pre-populated with various statuses)

#### Government Arguments
1. **Framework: Stability and freedom** (ANSWERED, STARRED)
   - Multi-layer clash tree showing Gov→Opp→Gov exchange
   - Demonstrates depth of analysis rebuilds

2. **Contention 1: Welfare cliffs elimination** (ANSWERED, STARRED)
   - Two separate analysis branches
   - Multiple clash layers (4-deep at one point)
   - 3 concrete examples included
   - Shows how to break an argument into multiple analysis points

3. **Contention 2: Recession stabilizer** (OPEN, STARRED)
   - Two high-level claims
   - 2 examples with specific data

4. **Extension: Labor market rebalancing** (OPEN)
   - Wage floor mechanism
   - 1 example showing real-world validation

#### Opposition Arguments
1. **Disadvantage: Institutional failure** (ANSWERED, STARRED)
   - Multi-layer clash with Gov responses
   - Shows how OPP can take ground back

2. **Disadvantage: Inflation** (TURNED)
   - Initial framing by Opposition
   - Gov takes it and turns it back
   - 4-deep clash showing turn dynamics
   - Demonstrates status progression (Opp loses ground)

3. **Impact turn: Dependency and autonomy** (ANSWERED)
   - Simpler 2-layer clash
   - Shows variety in argument depth

### Points of Information (3)
- 1 ACCEPTED (high-leverage question on means-testing)
- 1 DECLINED (cost-of-living question)
- 1 ACCEPTED (funding question in MG)

Each POI includes the timing (speech time in seconds where it was asked).

### Notes (by speech)
**PMC**: Framework setup, welfare cliff focus  
**LOC**: Institutional failure focus, IRS dysfunction  
**MG**: Inflation rebuttal, dependency turn-around  
**MO**: Labor shortage extension  
**LOR**: Summary comparison  
**PMR**: System coherence argument  

Each note captures the strategic focus of that speech.

## Features Demonstrated

### Clash Trees & Analysis Depth
- **Framework arg**: Shows real exchange structure (Gov claim → Opp rebuttal → Gov extension)
- **Welfare cliffs arg**: Demonstrates how to split one contention into multiple analysis nodes
- **Inflation disadvantage**: 4-layer deep clash showing how turns evolve

### Argument Status Lifecycle
- **Open**: Contention 2, Labor rebalancing (still being developed)
- **Answered**: Covered by opposition, but Gov has response ready
- **Turned**: Inflation DA (Gov takes Opp's own argument and flips it)
- **Dropped**: None in this sample (you can create by changing status in-round)

### Examples & Specificity
- Multiple arguments include concrete data points (percentages, dollar amounts, real programs)
- Shows how to ground abstract concepts in reality

### Multi-Speech Argument Development
- Contention 1 starts in PMC, gets responses in LOC, and Gov extends in MG and PMR
- Demonstrates how single arguments evolve across the round

## How to Use This to Learn

1. **Click "📚 Load sample"** → Debate loads instantly
2. **Expand each card** (click the arrow) to see clash trees
3. **Watch the timer** — use standard APDA times (PMC 7 min, LOC 8 min, etc.)
4. **Add POIs** during speeches using the POI input panel (right side)
5. **Mark status changes** as Opposition responds — click the status chip to cycle
6. **Take notes** in the right panel for each speech
7. **Export** at end with "Copy flow" button

---

## Keyboard Shortcuts (while flowing)
- **G** — New Government argument
- **O** — New Opposition argument
- **Space** — Start/pause timer
- **← →** — Previous/next speech
- **+** / **−** — Add/remove 30 seconds
- **R** — Reset current speech timer
- **T** — Toggle dark/light theme
- **E** — Export flow (copy to clipboard)
